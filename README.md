# 📊 Business Performance Dashboard – Excel

## 📌 Project Overview

This project is an **Excel Business Performance Dashboard** created to analyze and visualize fleet operations data.

The dataset contains **500 trip records** and includes information about revenue, profit, collections, payment methods, drivers, cities, and maintenance costs.

The main goal of this project was to transform raw data into meaningful insights that can help understand business performance and support better decision-making.

---

## 🎯 Project Objectives

- Analyze overall business performance.
- Track revenue and profit.
- Monitor collected and partially collected amounts.
- Analyze payment methods.
- Compare driver performance.
- Analyze revenue and profit by city.
- Analyze maintenance costs.
- Create a clear and interactive dashboard.
